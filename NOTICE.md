# Asal konten

Proyek ini berasal dari brosur PHP lokal bernama Hospitech. Data empat merek, judul, overview, 29 deskripsi fitur, nama brosur dan detail kontak dipertahankan dari array sumber. Template, navigasi, CSS lokal dan pembuat draft diperbarui untuk versi portfolio ini.

Sumber lokal menyebut “XSPec Hospitech redesign concept”. Penyebutan tersebut tidak membuktikan identitas penulis, afiliasi perusahaan atau persetujuan pabrikan. Tidak ada penulis, URL upstream atau lisensi yang dapat diverifikasi dari file brosur yang diaudit; repository ini tidak menetapkan lisensi baru untuk konten yang asal haknya belum jelas.

Nama Eurotronik, Intercall, Rondish, Medicare dan XSPec Hospitech merupakan referensi dalam konten sumber. Deskripsi produk dan detail bisnis belum diverifikasi secara independen. Proyek ini tidak menyatakan diri sebagai website resmi, perangkat klinis, sistem nurse-call operasional atau layanan kontak perusahaan.

Tidak ada PDF pabrikan, foto pasien/staf, data pelanggan atau kredensial yang diimpor. Ilustrasi ruang perawatan adalah diagram konseptual. Form hanya membuat draft teks lokal dan tidak menghubungi pihak lain.
